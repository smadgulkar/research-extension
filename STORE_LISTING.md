## Extension Name

## Short Description (132 characters max)

## Detailed Description

```
🧠 Research Assistant - Your AI-Powered Research Companion

Transform how you consume online content. Research Assistant uses AI to instantly analyze any webpage, giving you summaries, key points, and insights in seconds.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✨ KEY FEATURES

📖 Smart Page Analysis
• Get instant summaries in short, medium, or long formats
• Extract key points and main arguments automatically
• Identify topics and sentiment analysis
• Works on articles, documentation, research papers, and more

🧩 Personal Knowledge Base
• Every analysis builds your searchable knowledge base
• Ask questions across all your research
• AI-powered answers from your collected insights
• Organize with customizable workspaces

📤 Flexible Export Options
• Markdown export (free)
• JSON & HTML export (Pro)
• Obsidian integration with frontmatter & wikilinks (Pro)
• Notion database export (Pro)

🔒 Privacy-First Design
• Your API key stays on your device
• No tracking, no analytics, no data collection
• All data stored locally in your browser
• Direct API calls to OpenAI/Anthropic - we never see your data

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🚀 GETTING STARTED

1. Install the extension
2. Click the Research Assistant icon
3. Add your OpenAI or Anthropic API key in Settings
4. Navigate to any webpage and click "Analyze Page"

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

💡 PERFECT FOR

• Researchers analyzing academic papers
• Students summarizing study materials
• Professionals staying current with industry news
• Content creators gathering research
• Anyone who reads a lot online

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🔑 REQUIREMENTS

• An API key from OpenAI or Anthropic (bring your own key)
• Chrome browser (Manifest V3 compatible)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

⭐ PRO FEATURES

Upgrade to Pro to unlock:
• Export to JSON & HTML formats
• Obsidian integration with YAML frontmatter
• Notion database integration
• PDF analysis (coming soon)
• Citation generator (coming soon)
• Priority support

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Having issues? We're here to help!
• Check our documentation

Made with ❤️ for researchers everywhere.
```
